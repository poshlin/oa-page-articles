# 橘蘋觀點總覽頁｜真實資料版原型

橘子蘋果程式學院「橘蘋觀點」文章總覽頁的前端原型，使用公開文章資料呈現實際瀏覽、搜尋與篩選體驗。

## 目前內容

- 品牌化 Hero、文章搜尋與快速需求入口
- 本期精選與近期家長熱門文章
- 依程式學習、AI、升學認證、親子教育及未來職涯探索
- 熱門主題與其他標籤折疊
- 77 篇公開文章資料、封面、摘要與閱讀時間
- 桌面、平板與行動版響應式設計
- 分類、標籤、關鍵字單一條件篩選
- 篩選網址同步與返回狀態保留

## 查看方式

直接開啟根目錄的 `index.html`，或以任何靜態網站服務啟動本資料夾。

頁面只使用原生 HTML、CSS 與 JavaScript，不需要安裝套件。

## 主要檔案

- `index.html`：頁面結構
- `articles.css`：完整視覺與響應式樣式
- `articles-app.js`：搜尋、分類、標籤、展開與狀態邏輯
- `articles-real.js`：由橘蘋觀點公開頁面整理的原型資料

## 原型界線

- 免費體驗 CTA 在本機原型中不送出資料；正式上線時串接官網既有留單彈窗。
- 正式文章資料、後台、網址 routing 與查詢仍由橘子蘋果 Rails 官網負責。
- 本版本供內部檢視與設計確認，尚未進入正式工程交接。
